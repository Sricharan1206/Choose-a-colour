# Choose-a-colour
This project is inspired by my experience as a former member of the Pragati Toastmasters Club. During our Table Topics sessions, participants would pick a number or a slip of paper and then speak for 1–2 minutes based on the phrase or word provided.

I had an idea to digitize and enhance this experience using HTML. This led to the creation of an interactive Table Topics session on a webpage — turning a traditional segment into a more dynamic and creative experience for the club.

I was honored to take on the best high-stage role for that meeting.
